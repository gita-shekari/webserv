POST Upload Tests

Successful Upload

Select a file smaller than 10 MB. Expected response: 201 Created


Body Too Large

Select a file larger than 10 MB. Expected response: 413 Content Too Large


Other Upload Errors

  • POST to a location where POST is not allowed → 405 Method Not Allowed
  • Upload directory cannot be accessed → 403 Forbidden
  • Server fails while saving the file → 500 Internal Server Error
  • Malformed HTTP request → 400 Bad Request
